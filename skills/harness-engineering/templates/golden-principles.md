# Golden principles - {{CLUSTER}}

Rules this cluster learned the hard way. They are here because prose was the fastest way to write them
down, not because prose is where they belong.

**Every principle in this file is a rule that will eventually be broken.** Agents replicate whatever
patterns they find nearby, and a paragraph does not stop them. When a principle here can be checked by a
machine, promote it to `invariants.md` and delete it from this file. A principle that has survived here
for months without being mechanized is either not important or not mechanizable - decide which, and act.

## Format

Each principle gets: what the rule is, why it exists, and what happens when it is violated. The "why" is
the part that survives; a rule with no rationale gets discarded by the first agent that finds it
inconvenient.

```
### <short imperative>

**Rule:** ...
**Why:** ...
**Violation looks like:** ...
**Mechanizable?** yes -> see invariants.md | no, because ...
```
